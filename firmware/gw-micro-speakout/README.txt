Speak-Out firmware -- not included
==================================

The Speak-Out add-on runs the Speak-Out talking box's own firmware (hardware by Daniel
Weirich, software by Douglas Geoffray, GW Micro).  It is not in this repository.  The
released add-on carries it; to build the add-on yourself, put your own copy here:

  SPEAKOUT.HEX   sha256 1c6930c8c6aed0550bc267c14032f9195b450ed95de606f2fa9727e2b7eb1eb1

This folder's contents are ignored by git.
